# Battleship

Two-player Battleship for one device (pass and play). Works offline as an installable PWA, and keeps game history on the device.

- Secret fleet placement with a "pass the device" screen between turns
- Optional probability heatmap (off by default)
- Game history with multi-game Markdown export
- Local-first: everything is stored in the browser's localStorage

Static site, no build step. Open `index.html` over HTTP(S) to use the service worker and install prompt.
